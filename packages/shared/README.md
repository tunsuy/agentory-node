# @agentory/shared

Wire / DTO types shared by **agentory-node** adapters and (separately) the private Agentory control plane.

This package is **types + small helpers only** — no seat/quota enforcement, no HTTP server, no database. Enforcement and commercial logic live in the private product API.

Published under Apache-2.0 as part of the [agentory-node](https://github.com/tunsuy/agentory-node) open-source surface.
