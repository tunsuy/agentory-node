# Support

## How to get help

| Need | Where |
|------|--------|
| Bug in Host / adapter | [GitHub Issues](https://github.com/tunsuy/agentory-node/issues) — use a template |
| How to write an adapter | [docs/how-to-write-an-adapter.md](docs/how-to-write-an-adapter.md) |
| Contribution process | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Security vulnerability | [SECURITY.md](SECURITY.md) |
| Control plane / Console / hosted product | Not supported in this repo — use your Agentory product support channel |

## What this project is (and isn’t)

- **Is:** open-source node Host + RuntimeAdapter contract + in-tree adapters.
- **Isn’t:** the Agentory SaaS control plane, billing, or Console UI.

## Before opening an issue

1. Run `agentory-node version` (or `npx -y @agentoryhq/node version`).
2. Search existing issues for duplicates.
3. Redact tokens and personal paths from logs.
